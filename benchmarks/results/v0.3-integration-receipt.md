## End-to-end checklist

The acceptance run exercises every feature in one build:

- [x] **Flag gating** — with every flag flipped off, build page is byte-identical to v0.2 (verified via screenshot diff)
- [x] **JUnit dashboard** (`:junit`) — chengis-self build #3 (3,550 tests) shows summary card, sortable table, 30-build sparkline. Wall-clock to render: 2.4ms.
- [x] **Problem matchers** (`:problem-matchers`) — anvil-self build with intentional rustfmt warning produces a Problems-tab row with file:line:col + source.
- [x] **PR-check integration** (`:pr-checks`) — opening a PR on SuperBadLabs/anvil fires the webhook, anvil triggers a build, GitHub shows "anvil — in_progress" within 800ms; conclusion patched on `:build-done`.
- [x] **Matrix expander** (`:matrix`) — sample 3-axis matrix IR (JDK × OS × MAVEN) with one exclude expands to 8 cells via `expand-matrix`; grid view renders the 2D pivot correctly.
- [x] **Cron scheduler** (`:scheduler`) — `H/15` registration produces next-fire at +14m37s (hashed for `chengis-core-self`). The 15-min interval holds across 4 fires.
- [x] **Secrets** (`:secrets`) — `anvil secrets add docker-hub` from stdin → list shows masked preview only; `withCredentials([usernamePassword(...)])` binds env vars to a subprocess; the value appears as `****` in the streamed console (pre-bus redaction verified).
- [x] **mise auto-provision** (`:mise`) — workspace with `.tool-versions` declaring `nodejs 22.5.1` triggers `mise install` before the first `sh` step. Subsequent `sh 'node --version'` reports `v22.5.1`.

## Co-existence smoke

- All 7 flag-enabled features active simultaneously, dogfood handles ~4 hr soak run with 12 builds across 3 jobs; no thread / memory / CPU anomalies.
- SSE bus delivers `:test-completed`, `:problem-found`, `:checks-updated`, `:schedule-fired` events to a live `/anvil/events` subscriber without crosstalk.
- Database migrations 005 (test-results), 006 (problems), 007 (matrix columns) apply cleanly on top of TX11D's 004 (credentials).
- Per-build perf: 2.5ms p50 page render with all features rendering, well under 50ms TU0.7 budget.

## What was NOT exercised in this receipt

- **T4.4 matrix child-build dispatcher fan-out** — deferred to v0.3.1; the matrix IR/grid layer ships now without it.
- **T3 GitHub App auth** — PAT path verified; App auth deferred.
- **T5.4 Jenkinsfile `triggers { cron(…) }` translator** — config-driven path verified; Jenkinsfile-DSL parse deferred.

These deferrals are by design (see CHANGELOG.md and `docs/roadmap/v0.3-board.md`); the v0.3.x cycle picks them up.
